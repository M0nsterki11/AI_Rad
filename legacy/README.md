# Legacy files

Ovaj folder cuva stare pomocne datoteke radi povijesti projekta. One nisu dio
aktualnog multi-page pipelinea i nisu potrebne za pokretanje aplikacije,
treniranje modela ili evaluaciju.

- `notebooks/` sadrzi prazne notebook placeholdere iz pocetne strukture projekta.
- `scripts/` sadrzi jednokratne analiticke skripte za ranije eksperimente.
- `requirements/` sadrzi stare environment snapshot datoteke. Aktualne ovisnosti
  definirane su iskljucivo u root datoteci `requirements.txt`.

Datoteke su premjestene umjesto obrisane kako bi ostale dostupne za pregled
povijesti projekta.
